In a sorted array, two pointers can find a pair with a given sum without trying every pair. Start with `l` at the smallest value and `r` at the largest. If their sum is too small, the only way to increase it is to move `l` right; if it's too big, move `r` left. Each step rules out one value for good, so it takes O(n) time and O(1) extra space, compared with O(n²) for checking every pair.
